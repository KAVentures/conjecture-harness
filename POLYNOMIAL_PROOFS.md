# Exact polynomial certificates

The polynomial adapter supports rational polynomials of total degree at most eight, in up to four real variables, with at most 64 input terms. Claims are universal equality to zero or nonnegativity on all of R^n or the nonnegative orthant. General polynomial implications with constraints are not supported.

Example: (x^2-y^2)^2 >= 0 on R^2.

```python
from polynomial import statement, solve, replay
from polynomial_lab import discharge
from discovery import new
s = {"variables":["x","y"],"domain":"real","relation":"nonnegative",
     "terms":[[[4,0],1],[[2,2],-2],[[0,4],1]]}
r = solve(s)
assert r["status"] == "proved" and replay(s,r["certificate"])
g, evidence = discharge(new(statement(s)), "goal", s)
```

Each term contains an exponent vector and an exact rational coefficient. Use the canonical statement generated by statement(s) to bind the evidence to a graph node; separately justify any translation from the original mathematical claim. Variable order and domain matter.

Identity checking combines coefficients exactly. Nonnegativity search tries nonnegative monomials and a restricted Gram-matrix construction with exact rational square decomposition. A separate expansion of the weighted squares and admissible nonnegative monomials verifies the polynomial identity; positive weights and valid exponents guarantee nonnegativity. The search is incomplete: one chosen Gram representation may fail although another succeeds. It is not a semidefinite optimization solver. When proofs are not found, a bounded rational grid seeks counterexamples; every witness is evaluated exactly. A failed grid search is unknown, not proof. For instance the Motzkin polynomial is a known nonnegative control this restricted search leaves unknown.

The discovery runner invokes this adapter automatically on reachable canonical polynomial claims, up to two per pass, before requesting model proposals. Only replayed evidence changes a claim's status; a refuted auxiliary claim does not refute the target. Generated model text cannot impersonate reserved certificate observations. The graph state is locally operator-controlled, not cryptographically authenticated. Preserve the specification, certificate and dependency bridge in any research package.

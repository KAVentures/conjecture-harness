# Release gates

0.6.0-preview is a public chat-first usability preview. It is not a guaranteed conjecture solver and no novel mathematical discovery is claimed by this release.

The local experimental Python development distribution passed 63 unit tests (including 15 new proof-state and runner tests) (including 135 small-graph comparisons against brute force, 16 rational permanent cross-checks, package integrity, citation consistency and hostile/malformed inputs). These are bounded implementation checks, not validation of arbitrary proof correctness. The Python source, tests and known-control LaTeX source are included in the public repository; the chat-first protocol is usable without running them. This preview has not yet undergone a fresh independent ChatGPT test, authenticated multi-model orchestration, formal proof-assistant evaluation, independent replication or demonstrated superiority over prompting alone. No DOI has been registered. CI is configured to run unit tests, exact finite benchmarks, official CFF schema validation and the known-control paper build. Remote results must be checked before claiming success. Do not treat repository structure, source labels, model review or a manifest as mathematical certification.

## Discovery upgrade status

The new graph implements AND/OR obligations, candidate implications, operator-reviewed evidence, observations, a stagnation escape policy and bounded serial model proposals. The chat protocol additionally prescribes recursive decomposition, bidirectional bridging, cross-domain transfer and counterexample-driven evolution. These are not automatically mathematically validated by the engine. Live discovery, formal verification, semantic equivalence, genuine independent orchestration and comparative scientific performance remain unproven. See evidence/discovery-v06.md.

## Proposed controlled evaluation
Freeze solved controls, held-out recently solved targets and genuinely open targets; prevent target drift and report possible training leakage. Compare single-model continuation, independent stochastic sampling, fixed multi-agent portfolio and adaptive portfolio at matched model, inference budget, tool access and wall-time policies. Report all failures, costs, exact target fingerprints, toolchain versions and logs. Primary endpoint: faithful formal proof or independently replayable exact counterexample. Secondary: verified new lemmas, errors caught, compute cost and time. Model approval alone scores zero. Novelty requires primary-source audit and expert review. No bounded negative search establishes first priority.

## Preview acceptance
A fresh chat should load the actual protocol at one revision; make substantive mathematical progress; preserve a checkpoint; generate a known-control package with a complete proof and reproducibility inputs; confirm authorship; produce both paper and repository citations; provide actual files and verify any authorized upload. Test with and without web and shell access; report missing capabilities. A known control tests the workflow, not open-problem solving.

# Checked literature-to-theorem transfer

First implemented theorem family: the complement-homomorphism preorder used by J. Zuiddam, "The asymptotic spectrum of graphs and the Shannon capacity" (Combinatorica, 2019; https://arxiv.org/abs/1807.00169). The elementary proof of the specific rule follows; no unverified claim from a source is accepted automatically.

Given goal capacity(G) <= t and premise capacity(H) <= u, seek a complement homomorphism from the k-th strong power of G to H, together with u <= t^k. Every pair of distinguishable vertices must map to distinct distinguishable vertices. For every m, apply the map to consecutive length-k blocks of codewords in G^(km); each independent set maps injectively to an independent set of H^m, since two distinct codewords have a distinguishable coordinate and hence a distinguishable block. Therefore alpha(G^(km)) <= alpha(H^m). By supermultiplicativity of the independence numbers and Fekete's lemma, their exponential growth limit exists and is unchanged along multiples of k. Taking roots and limits gives capacity(G)^k <= capacity(H) <= u <= t^k. This establishes the conditional bridge. It does not assume that Shannon capacity is multiplicative for two different graphs or that it is additive under disjoint union.

The adapter automatically searches for a map using bounded backtracking, with exact graph construction, smallest-domain-first variable selection, rational bound comparison and independent replay. It supports maps into unrelated graphs, not only induced subgraphs. Power graphs are limited to 32 vertices and k<=5; each call attempts at most 10,000 search nodes. The runner tries at most two applications per pass, with 1,000 nodes each. Unknown search results remain unknown.

A candidate single-premise edge is accepted only after the map and numerical condition pass replay. The premise must still be proved separately. The adapter can also discover a new edge to an already-established graph-capacity claim, thereby turning previously disconnected work into a target-relevant proof. It inherits the premise's review trust; it does not promote an unreviewed source or a model claim into a theorem. Every application records a source locator and exact witness. A dependency cycle is rejected.

For general literature-derived results not covered by this rule, extract the exact statement, assumptions, definitions, source locator and direction of implication; map those assumptions into the target; explicitly create a new obligation for each missing condition; audit the bridge separately. This is still a human/model research procedure, not an automated general literature parser. No automatic use of arbitrary externally supplied theorem rules is supported.

Reproduction: python -m unittest discover -s tests -p test_theorem_transfer.py -v. Thirteen focused tests pass, covering power identity, independent map replay, insufficient bounds, wrong direction, unreviewed premises, conditional closure, automatic reuse and invalid maps. Full regression: 263 distinct tests passed across two invocations (226 completed before the full-run timeout, 39 in the follow-up, two overlapping). No new Shannon-capacity bound or live model performance claim.
